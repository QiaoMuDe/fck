## 简介

FCK 是一个功能丰富的跨平台命令行工具集，集成了文件操作、文本处理、系统监控、压缩解压等 30+ 实用工具。无论是日常文件管理、文本处理、系统监控，还是开发辅助工作，FCK 都能提供高效便捷的解决方案。

### 为什么选择 FCK？

- **一站式解决方案**：覆盖文件操作、文本处理、系统监控、开发辅助等多个场景
- **跨平台支持**：Windows、Linux、macOS 全平台兼容
- **现代化设计**：彩色输出、表格样式、进度显示、交互式体验
- **高性能**：并发处理、流式操作、内存优化
- **管道友好**：所有命令都支持标准输入输出，便于组合使用

## ✨ 功能特性

### 🔐 文件校验 (hash)
- **多算法支持**: MD5、SHA1、SHA256、SHA512
- **批量处理**: 支持通配符和递归扫描
- **完整性验证**: 生成和验证校验文件
- **高性能**: 并发计算，显著提升处理速度

### 📊 智能统计 (size/df)
- **精确计算**: 文件和目录大小统计 (size)
- **磁盘空间**: 显示文件系统磁盘空间使用情况 (df)
- **人性化显示**: 自动选择最佳单位 (B/KB/MB/GB/TB)
- **进度显示**: 大目录扫描时显示实时进度
- **隐藏文件**: 可选择包含或排除隐藏文件

### 🔍 高级查找 (find)
- **多条件筛选**: 按名称、大小、时间、类型等组合查找
- **正则支持**: 强大的正则表达式匹配
- **并发搜索**: 多线程并行处理，提升搜索效率
- **批量操作**: 支持删除、移动、执行命令等批量操作

### 📋 目录列表 (list)
- **多种排序**: 按名称、大小、时间排序
- **彩色显示**: 根据文件类型智能着色
- **表格样式**: 20+种表格样式可选
- **详细信息**: 显示权限、用户组、修改时间等

### ✅ 文件校验 (check)
- **完整性验证**: 根据哈希文件验证文件完整性
- **多算法支持**: 支持MD5、SHA1、SHA256、SHA512
- **并发校验**: 多线程并行处理，提升验证速度
- **详细报告**: 显示校验通过、失败和错误统计

### 📦 文件打包 (pack)
- **多格式支持**: 支持多种压缩格式的文件打包
- **智能过滤**: 支持包含/排除模式、文件大小过滤
- **压缩级别**: 可调节压缩级别，平衡压缩率和速度
- **进度显示**: 实时显示打包进度和状态

### 📂 文件解包 (unpack)
- **格式自动识别**: 自动识别压缩包格式并解压
- **选择性解压**: 支持过滤器，选择性解压文件
- **覆盖控制**: 可选择是否覆盖已存在的文件
- **进度跟踪**: 显示解压进度和详细信息

### 👁️ 压缩包预览 (preview)
- **内容预览**: 无需解压即可查看压缩包内容
- **详细信息**: 显示压缩包统计信息和文件列表
- **限制输出**: 支持限制显示文件数量
- **多种模式**: 简洁模式和详细模式可选

### ⏱️ 命令监控 (watch)
- **周期性执行**: 按指定间隔重复执行命令并显示结果
- **差异高亮**: 高亮显示变化的行（黄色标记）
- **精确计时**: 可选精确计时模式，补偿命令执行耗时
- **灵活控制**: 支持执行次数限制、超时设置、错误退出
- **智能输出**: 自动合并 stdout 和 stderr，动态适配终端宽度
- **安全限制**: 输出大小限制（stdout 10MB），防止内存溢出

### 🌐 端口查看 (port)
- **协议过滤**: 支持 TCP/UDP 协议筛选
- **进程关联**: 显示占用端口的进程信息
- **状态过滤**: 按连接状态（LISTEN/ESTABLISHED 等）过滤
- **多种格式**: 表格、简洁、JSON 多种输出格式

### 📊 进程查看 (proc)
- **灵活过滤**: 支持按进程名、PID 过滤
- **多维排序**: 支持按 PID、名称、CPU、内存、时间排序
- **树形显示**: 以树状结构展示进程父子关系
- **多种格式**: 表格、简洁、树形、JSON 多种输出格式

### 📝 文本处理 (sed)
- **多模式替换**: 支持字符串和正则表达式替换
- **原地修改**: 支持直接修改文件（带备份功能）
- **行范围**: 支持指定行号范围进行替换
- **二进制检测**: 自动检测并处理二进制文件
- **管道支持**: 支持从标准输入读取内容

### 🔧 字段处理 (awk/wc)
- **简化版 awk**: 使用标志控制替代程序解析
- **字段提取**: 支持按索引提取字段（1-based，0=整行，-1=最后一个字段）
- **模式匹配**: 支持正则表达式过滤行
- **灵活分隔符**: 默认任意空白，支持自定义分隔符
- **字数统计**: 统计行数、单词数、字节数、字符数 (wc)
- **最大行宽**: 支持统计最大行长度 (wc)
- **管道支持**: 支持从标准输入读取内容
- **大文件支持**: 使用 bufio.Reader，支持任意行长度
- **多文件处理**: 支持同时处理多个文件
- **通配符支持**: 跨平台通配符展开（*.txt, logs/*.log）

### 🔎 文本搜索 (grep)
- **正则匹配**: 支持正则表达式搜索
- **忽略大小写**: 可选大小写不敏感匹配
- **行号显示**: 显示匹配行的行号
- **文件名前缀**: 多文件搜索时显示文件名
- **递归搜索**: 支持递归目录搜索

### 📁 文件操作 (cp/mv/rm/mkdir/touch/truncate)
- **复制**: 支持递归复制、进度显示、保留属性
- **移动**: 跨文件系统移动、自动创建目录
- **删除**: 递归删除、交互式确认、安全删除
- **创建**: 目录递归创建、空文件创建、时间戳更新
- **截断**: 文件大小调整

### 🖥️ 文件查看 (cat/head/tail)
- **语法高亮**: 支持多种编程语言的语法高亮 (cat)
- **分页显示**: 大文件自动分页 (cat)
- **行号显示**: 可选显示行号 (cat)
- **文件头查看**: 显示文件开头内容，支持按行数或字节数 (head)
- **文件尾查看**: 显示文件结尾内容，支持实时追踪模式 (tail)
- **管道支持**: head/tail 支持从标准输入读取

### 🔄 字符转换 (tr)
- **字符映射**: 支持字符集之间的转换（如大小写转换）
- **字符删除**: 删除指定字符集中的字符
- **字符压缩**: 将连续重复的字符压缩为单个
- **字符范围**: 支持范围表示（如 `a-z`, `0-9`）
- **转义字符**: 支持 `\n`, `\t`, `\\` 等转义序列
- **补集模式**: 对字符集取反操作
- **管道支持**: 支持从标准输入读取

### ⚡ 参数处理 (xargs)
- **批量执行**: 从标准输入读取参数批量执行
- **并发控制**: 支持并发执行提升效率
- **参数分组**: 支持将多个参数作为一组传递
- **超时控制**: 支持命令执行超时设置

### 🔗 别名生成 (alias)
- **多Shell支持**: 支持 Bash、Zsh、PowerShell
- **模板生成**: 自动生成对应 Shell 的别名配置
- **快速配置**: 一键复制粘贴配置到 Shell

### 🌿 Git 工具 (gm)
- **模型管理**: Git 工作流模型快速切换
- **仓库管理**: 简化 Git 仓库操作流程

### 📄 Markdown 预览 (md)
- **实时渲染**: 在终端中渲染 Markdown 文件
- **多种样式**: 支持多种主题样式（dark、light、dracula 等）
- **分页查看**: 支持分页器查看大文件
- **管道支持**: 支持从标准输入读取 Markdown 内容
- **自动换行**: 支持自定义换行宽度

### 🔎 命令查找 (which)
- **环境查找**: 在 PATH 环境变量中查找命令的可执行文件路径
- **多命令支持**: 支持同时查找多个命令
- **显示所有匹配**: 可选显示所有匹配的路径（而非仅第一个）
- **静默模式**: 支持静默检查，便于脚本中使用
- **跨平台**: 自动适配 Windows 和 Unix-like 系统的可执行文件规则

## 🚀 快速开始

### 环境要求
- Go 1.24.4+ 
- 支持 Windows、Linux、macOS

### 安装方式

#### 方式一：源码编译
```bash
# 克隆仓库
git clone https://gitee.com/MM-Q/fck.git
cd fck

# 开发版本（生成到 output 目录）
python3 build.py

# 正式版本（安装到 $GOPATH/bin）
python3 build.py -s -ai -f

# 发布版本（压缩包）
python3 build.py -batch -z
```

#### 方式二：直接运行
```bash
go run main.go [命令] [选项]
```
