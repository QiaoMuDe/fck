## ✨ 功能特性

### 🔐 文件校验 (hash)
- **多算法支持**: MD5、SHA1、SHA256、SHA512
- **批量处理**: 支持通配符和递归扫描
- **完整性验证**: 生成和验证校验文件
- **高性能**: 并发计算，显著提升处理速度

### 📊 智能统计 (size)
- **精确计算**: 文件和目录大小统计
- **人性化显示**: 自动选择最佳单位 (B/KB/MB/GB/TB)
- **进度显示**: 大目录扫描时显示实时进度
- **隐藏文件**: 可选择包含或排除隐藏文件

### 🔍 高级查找 (find)
- **多条件筛选**: 按名称、大小、时间、类型等组合查找
- **正则支持**: 强大的正则表达式匹配
- **并发搜索**: 多线程并行处理，提升搜索效率
- **批量操作**: 支持删除、移动、执行命令等批量操作

### 📋 目录列表 (list)
- **多种排序**: 按名称、大小、时间排序
- **彩色显示**: 根据文件类型智能着色
- **表格样式**: 20+种表格样式可选
- **详细信息**: 显示权限、用户组、修改时间等

### ✅ 文件校验 (check)
- **完整性验证**: 根据哈希文件验证文件完整性
- **多算法支持**: 支持MD5、SHA1、SHA256、SHA512
- **并发校验**: 多线程并行处理，提升验证速度
- **详细报告**: 显示校验通过、失败和错误统计

### 📦 文件打包 (pack)
- **多格式支持**: 支持多种压缩格式的文件打包
- **智能过滤**: 支持包含/排除模式、文件大小过滤
- **压缩级别**: 可调节压缩级别，平衡压缩率和速度
- **进度显示**: 实时显示打包进度和状态

### 📂 文件解包 (unpack)
- **格式自动识别**: 自动识别压缩包格式并解压
- **选择性解压**: 支持过滤器，选择性解压文件
- **覆盖控制**: 可选择是否覆盖已存在的文件
- **进度跟踪**: 显示解压进度和详细信息

### 👁️ 压缩包预览 (preview)
- **内容预览**: 无需解压即可查看压缩包内容
- **详细信息**: 显示压缩包统计信息和文件列表
- **限制输出**: 支持限制显示文件数量
- **多种模式**: 简洁模式和详细模式可选

### ⏱️ 命令监控 (watch)
- **周期性执行**: 按指定间隔重复执行命令并显示结果
- **差异高亮**: 高亮显示变化的行（黄色标记）
- **精确计时**: 可选精确计时模式，补偿命令执行耗时
- **灵活控制**: 支持执行次数限制、超时设置、错误退出
- **智能输出**: 自动合并 stdout 和 stderr，动态适配终端宽度
- **安全限制**: 输出大小限制（stdout 10MB），防止内存溢出

### 📝 文本处理 (sed)
- **多模式替换**: 支持字符串和正则表达式替换
- **原地修改**: 支持直接修改文件（带备份功能）
- **行范围**: 支持指定行号范围进行替换
- **二进制检测**: 自动检测并处理二进制文件
- **管道支持**: 支持从标准输入读取内容

### 🔎 文本搜索 (grep)
- **正则匹配**: 支持正则表达式搜索
- **忽略大小写**: 可选大小写不敏感匹配
- **行号显示**: 显示匹配行的行号
- **文件名前缀**: 多文件搜索时显示文件名
- **递归搜索**: 支持递归目录搜索

### 📁 文件操作 (cp/mv/rm/mkdir/touch/truncate)
- **复制**: 支持递归复制、进度显示、保留属性
- **移动**: 跨文件系统移动、自动创建目录
- **删除**: 递归删除、交互式确认、安全删除
- **创建**: 目录递归创建、空文件创建、时间戳更新
- **截断**: 文件大小调整

### 🖥️ 文件查看 (cat)
- **语法高亮**: 支持多种编程语言的语法高亮
- **分页显示**: 大文件自动分页
- **行号显示**: 可选显示行号
- **文件限制**: 自动限制超大文件显示

### ⚡ 参数处理 (xargs)
- **批量执行**: 从标准输入读取参数批量执行
- **并发控制**: 支持并发执行提升效率
- **参数分组**: 支持将多个参数作为一组传递
- **超时控制**: 支持命令执行超时设置

### 🔗 别名生成 (alias)
- **多Shell支持**: 支持 Bash、Zsh、PowerShell
- **模板生成**: 自动生成对应 Shell 的别名配置
- **快速配置**: 一键复制粘贴配置到 Shell

### 🌿 Git 工具 (gm)
- **模型管理**: Git 工作流模型快速切换
- **仓库管理**: 简化 Git 仓库操作流程

### 📄 Markdown 预览 (md)
- **实时渲染**: 在终端中渲染 Markdown 文件
- **多种样式**: 支持多种主题样式（dark、light、dracula 等）
- **分页查看**: 支持分页器查看大文件
- **管道支持**: 支持从标准输入读取 Markdown 内容
- **自动换行**: 支持自定义换行宽度

## 🚀 快速开始

### 环境要求
- Go 1.24.4+ 
- 支持 Windows、Linux、macOS

### 安装方式

#### 方式一：源码编译
```bash
# 克隆仓库
git clone https://gitee.com/MM-Q/fck.git
cd fck

# 开发版本（生成到 output 目录）
python3 build.py

# 正式版本（安装到 $GOPATH/bin）
python3 build.py -s -ai -f

# 发布版本（压缩包）
python3 build.py -batch -z
```

#### 方式二：直接运行
```bash
go run main.go [命令] [选项]
```

## 📖 命令详解

### 🔐 hash - 文件哈希计算
计算文件或目录的哈希值，支持完整性验证和校验文件生成。支持MD5、SHA1、SHA256、SHA512算法。

### 📊 size - 文件大小统计
统计文件或目录的磁盘占用空间，支持人性化显示和进度条。

### 🔍 find - 高级文件查找
强大的文件搜索工具，支持多条件组合查找、正则表达式、并发搜索和批量操作。

### 📋 list - 目录内容列表
增强版的目录列表工具，提供丰富的显示选项、多种排序方式和表格样式。

### ✅ check - 文件完整性校验
根据哈希文件验证文件完整性，支持多种哈希算法和并发校验。

### 📦 pack - 文件打包压缩
将文件或目录打包成压缩文件，支持多种压缩格式、智能过滤和进度显示。

### 📂 unpack - 文件解包解压
解压缩文件到指定目录，支持格式自动识别、选择性解压和覆盖控制。

### 👁️ preview - 压缩包预览
预览压缩包内容和信息，无需解压即可查看文件列表和统计数据。

### ⏱️ watch - 命令监控
周期性执行指定命令并显示输出结果，类似 Linux watch 命令。支持差异高亮、精确计时、输出限制等高级功能。

### 📝 sed - 文本替换
强大的流编辑器，支持字符串和正则表达式替换。支持原地修改、行范围、最大替换次数、二进制文件检测等功能。

### 🔎 grep - 文本搜索
在文件中搜索匹配的文本，支持正则表达式、忽略大小写、行号显示、文件名前缀等功能。

### 📁 cp - 文件复制
增强的文件复制命令，支持递归复制、进度显示、覆盖控制、保留属性等功能。

### 📂 mv - 文件移动
安全的文件移动命令，支持跨文件系统移动、自动创建目标目录、覆盖控制等功能。

### 🗑️ rm - 文件删除
安全的文件删除命令，支持递归删除、交互式确认、强制删除等功能。

### 📂 mkdir - 目录创建
创建目录，支持递归创建多级目录、设置权限等功能。

### 📄 touch - 文件创建/时间戳更新
创建空文件或更新文件访问和修改时间戳。

### ✂️ truncate - 文件截断
截断或扩展文件到指定大小。

### 🖥️ cat - 文件内容查看
查看文件内容，支持语法高亮、分页显示、行号、文件大小限制等功能。

### 🏠 home - 用户主目录
显示当前用户的主目录路径。

### 📍 pwd - 当前工作目录
显示当前工作目录路径。

### 📅 date - 日期时间显示
显示当前日期和时间，支持多种格式。

### 📢 echo - 文本输出
输出文本内容，支持转义序列、不换行等选项。

### ⚡ xargs - 参数批量处理
从标准输入读取参数并执行命令，支持并发执行、参数分组、超时控制等功能。

### 🔗 alias - Shell 别名生成
为常用命令生成 Shell 别名，支持 Bash、Zsh、PowerShell 等多种 Shell。

### 🌿 gm - Git 模型管理
Git 仓库模型管理工具，支持快速切换和管理 Git 工作流。

### 📄 md - Markdown 预览
在终端中渲染和预览 Markdown 文件，支持多种主题样式、分页查看和管道输入。
