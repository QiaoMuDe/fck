# Touch 命令设计方案

## 功能概述
实现一个用于创建空文件和更新文件时间戳的命令 `touch`，支持创建文件、更新时间戳、设置特定时间等功能，提供便捷的文件操作。

## 核心功能

### 1. 创建空文件
- 支持创建单个空文件
- 支持创建多个空文件
- 支持指定文件路径

### 2. 更新时间戳
- 更新文件的访问时间和修改时间为当前时间
- 如果文件不存在，则创建空文件

### 3. 设置特定时间
- 支持设置文件的访问时间
- 支持设置文件的修改时间
- 支持同时设置访问时间和修改时间

### 4. 不创建文件
- 只更新已存在文件的时间戳
- 不创建新文件

### 5. 错误处理
- 检测文件是否已存在
- 检测权限是否足够
- 提供友好的错误提示

### 6. 详细输出
- 支持显示创建的文件
- 支持显示更新的文件
- 支持显示操作统计信息

## 命令选项设计

| 选项 | 短选项 | 说明 | 默认值 |
|------|--------|------|--------|
| `--no-create` | `-c` | 不创建文件（仅更新时间戳） | false |
| `--time` | `-t` | 设置时间（格式：YYYYMMDDHHMM.SS） | 当前时间 |
| `--access` | `-a` | 只更新访问时间 | false |
| `--modify` | `-m` | 只更新修改时间 | false |
| `--verbose` | `-v` | 显示操作的文件 | false |

## 使用示例

### 创建空文件
```bash
fck touch newfile.txt
# 创建 newfile.txt 空文件
```

### 创建多个文件
```bash
fck touch file1.txt file2.txt file3.txt
# 创建多个空文件
```

### 更新已存在文件的时间戳
```bash
fck touch existingfile.txt
# 更新 existingfile.txt 的访问时间和修改时间为当前时间
```

### 不创建文件（仅更新时间戳）
```bash
fck touch -c nonexistent.txt
# 文件不存在，不创建，也不报错
```

### 设置特定时间
```bash
fck touch -t 202401011230.00 file.txt
# 设置文件时间为 2024-01-01 12:30:00
```

### 只更新访问时间
```bash
fck touch -a file.txt
# 只更新访问时间
```

### 只更新修改时间
```bash
fck touch -m file.txt
# 只更新修改时间
```

### 详细输出
```bash
fck touch -v newfile.txt
# 输出: 创建文件: newfile.txt
```

### 组合使用
```bash
fck touch -cv -t 202401011230.00 file.txt
# 不创建文件，显示详情，设置特定时间
```

## 实现细节

### 1. 配置结构体

```go
type TouchConfig struct {
    Targets   []string
    NoCreate  bool
    Time      string
    Access    bool
    Modify    bool
    Verbose   bool
}
```

### 2. 核心处理流程

```
1. 解析命令行参数，构建 TouchConfig
2. 解析时间参数：
   - 如果 Time 为空，使用当前时间
   - 如果 Time 不为空，解析为时间对象
3. 处理每个目标文件：
   - 检查文件是否存在
   - 如果不存在且 NoCreate=false，创建空文件
   - 如果不存在且 NoCreate=true，跳过
   - 如果存在，更新时间戳
4. 输出结果：
   - 如果 Verbose=true，显示操作的文件
   - 显示操作统计信息
```

### 3. 创建文件逻辑

```
1. 检查文件是否存在
2. 如果存在：
   - 更新时间戳
   - 如果 Verbose=true，输出更新信息
3. 如果不存在：
   - 如果 NoCreate=true，跳过
   - 如果 NoCreate=false，创建空文件
   - 如果 Verbose=true，输出创建信息
```

### 4. 时间戳更新逻辑

```
1. 确定要更新的时间：
   - 如果 Time 为空，使用当前时间
   - 如果 Time 不为空，使用指定时间
2. 确定要更新的时间类型：
   - 如果 Access=true 且 Modify=false，只更新访问时间
   - 如果 Modify=true 且 Access=false，只更新修改时间
   - 如果 Access=false 且 Modify=false，更新访问时间和修改时间
3. 调用 os.Chtimes 更新时间戳
```

### 5. 时间解析

时间格式：YYYYMMDDHHMM.SS
- YYYY：4 位年份
- MM：2 位月份
- DD：2 位日期
- HH：2 位小时（24 小时制）
- MM：2 位分钟
- SS：2 位秒数（可选，默认为 00）

示例：
- 202401011230.00 → 2024-01-01 12:30:00
- 202401011230 → 2024-01-01 12:30:00

### 6. 错误处理

支持的错误类型：
- 权限不足
- 路径无效
- 磁盘空间不足
- 父目录不存在
- 时间格式错误

错误处理策略：
- 默认遇到错误停止
- NoCreate=true 时，文件不存在不报错
- 提供详细的错误信息

## 边界情况处理

1. **空目标列表**：提示错误，不执行任何操作
2. **文件已存在**：更新时间戳，不报错
3. **文件不存在且 NoCreate=true**：跳过，不报错
4. **时间格式错误**：使用当前时间或提示错误
5. **父目录不存在**：报错，提示需要先创建目录
6. **权限不足**：报错，提示权限问题
7. **符号链接**：更新链接指向的文件时间戳
