# seq 命令设计方案

## 一、需求概述

生成数字序列，类似于 Unix/Linux 的 `seq` 命令。支持指定起始值、结束值、步长，以及多种输出格式。

## 二、核心思路

1. **灵活的参数解析**：支持 1-3 个位置参数（结束值 / 起始+结束 / 起始+步长+结束）
2. **多种输出格式**：默认换行分隔、自定义分隔符、等宽格式
3. **边界处理**：处理负数、小数、反向序列（步长为负）
4. **格式化选项**：支持 printf 风格的格式字符串

## 四、关键逻辑设计

### 4.1 配置结构体

```go
// SeqConfig 配置结构体
type SeqConfig struct {
	Start      float64 // 起始值
	End        float64 // 结束值
	Step       float64 // 步长
	Separator  string  // 分隔符（默认换行）
	Terminator string  // 终止符（默认换行）
	Format     string  // 格式字符串（如 "%04g"）
	EqualWidth bool    // 等宽输出（自动补零）
}
```

### 4.2 核心算法

```
1. 解析位置参数（1-3个）
   - 1个参数: START=1, STEP=1, END=arg1
   - 2个参数: START=arg1, STEP=1, END=arg2
   - 3个参数: START=arg1, STEP=arg2, END=arg3

2. 验证参数
   - 步长不能为0
   - 检查序列方向（正向/反向）

3. 生成序列
   - 当前值 = START
   - while 当前值 <= END（正向）或 当前值 >= END（反向）:
     - 输出当前值
     - 当前值 += STEP

4. 格式化输出
   - 应用 Format 或 EqualWidth 选项
   - 使用 Separator 分隔，Terminator 结尾
```

### 4.3 边界条件处理

- **步长为0**：返回错误
- **无限循环**：检测步长方向与起止值关系
- **浮点精度**：使用适当精度处理浮点数比较
- **空序列**：起止值关系与步长方向矛盾时输出空

## 五、选项设计

| 长选项 | 短选项 | 类型 | 默认值 | 说明 |
|-------|-------|-----|-------|-----|
| `--separator` | `-s` | string | `"\n"` | 分隔符（支持转义字符如 `\t`） |
| `--terminator` | `-t` | string | `"\n"` | 终止符 |
| `--format` | `-f` | string | `""` | 格式字符串（如 `%04g`、`%.2f`） |
| `--equal-width` | `-w` | bool | false | 等宽输出（自动计算宽度） |

## 六、输出格式说明

### 6.1 默认格式
```bash
fck seq 5
# 输出:
# 1
# 2
# 3
# 4
# 5
```

### 6.2 自定义分隔符
```bash
fck seq -s " " 5
# 输出: 1 2 3 4 5

fck seq -s ", " 2 5
# 输出: 2, 3, 4, 5
```

### 6.3 格式字符串
```bash
fck seq -f "%04g" 5
# 输出:
# 0001
# 0002
# 0003
# 0004
# 0005

fck seq -f "%.2f" 0 0.5 2
# 输出:
# 0.00
# 0.50
# 1.00
# 1.50
# 2.00
```

### 6.4 等宽输出
```bash
fck seq -w 10 15
# 输出:
# 10
# 11
# 12
# 13
# 14
# 15

fck seq -w 99 101
# 输出:
# 099
# 100
# 101
```

### 6.5 反向序列
```bash
fck seq 5 -1 1
# 输出:
# 5
# 4
# 3
# 2
# 1
```

## 七、使用示例

```bash
# 基础用法
fck seq 5              # 1 到 5
fck seq 2 5            # 2 到 5
fck seq 0 2 10         # 0 到 10，步长 2

# 小数支持
fck seq 0 0.5 2        # 0, 0.5, 1, 1.5, 2

# 自定义分隔符
fck seq -s " " 5       # 1 2 3 4 5
fck seq -s "," 5       # 1,2,3,4,5
fck seq -s "\t" 5      # 制表符分隔

# 格式控制
fck seq -f "%04g" 5    # 0001 到 0005
fck seq -w 99 101      # 099, 100, 101
fck seq -f "%.2f" 0 0.5 2

# 反向序列
fck seq 10 -2 0        # 10, 8, 6, 4, 2, 0

# 无终止符（配合其他命令）
fck seq -t "" -s " " 5 | xargs echo
```

## 八、边缘案例

1. **步长为0**：返回错误 "step cannot be zero"
2. **起止值与步长方向矛盾**：如 `seq 1 1 5`（步长为负但起始<结束），输出空
3. **浮点精度**：处理如 `seq 0 0.1 0.3` 的精度问题
4. **极大数值**：处理大数时的溢出问题
5. **负步长**：支持反向生成序列

## 十、技术选型依据

1. **浮点数处理**：使用 `float64` 支持小数序列
2. **格式化**：使用 `fmt.Sprintf` 支持格式字符串
3. **转义字符**：使用 `strconv.Unquote` 或手动处理 `\t`, `\n` 等
4. **精度控制**：生成序列时使用容差值比较浮点数
