# Mkdir 命令设计方案

## 功能概述
实现一个用于创建目录的命令 `mkdir`，支持递归创建、权限设置、错误处理等功能，提供便捷的目录创建操作。

## 核心功能

### 1. 基本创建功能
- 支持创建单个目录
- 支持创建多个目录
- 支持指定目录路径

### 2. 递归创建
- 支持递归创建父目录（类似 `mkdir -p`）
- 自动创建不存在的父目录
- 跳过已存在的目录

### 3. 权限设置
- 支持设置目录权限（八进制模式）
- 支持常用权限别名（755, 777等）

### 4. 错误处理
- 检测目录是否已存在
- 检测权限是否足够
- 提供友好的错误提示

### 5. 详细输出
- 支持显示创建的目录路径
- 支持显示跳过的目录
- 支持显示创建统计信息

## 命令选项设计

| 选项 | 短选项 | 说明 | 默认值 |
|------|--------|------|--------|
| `--parents` | `-p` | 递归创建父目录 | false |
| `--mode` | `-m` | 设置目录权限（八进制，如 755） | 0755 |
| `--verbose` | `-v` | 显示创建的目录 | false |

**注意**：
- 输出内容通过位置参数传递，支持多个目录
- 使用 -p 选项递归创建父目录（使用 os.MkdirAll）
- 不使用 -p 时，只创建目标目录（使用 os.Mkdir）

## 使用示例

### 基本创建
```bash
fck mkdir newdir
# 创建 newdir 目录
```

### 创建多个目录
```bash
fck mkdir dir1 dir2 dir3
# 创建多个目录
```

### 递归创建
```bash
fck mkdir -p parent/child/grandchild
# 递归创建 parent、child、grandchild 目录
# 如果 parent 已存在，只创建 child 和 grandchild
```

### 设置权限
```bash
fck mkdir -m 755 newdir
# 创建目录并设置权限为 755
```

### 详细输出
```bash
fck mkdir -v newdir
# 输出: 创建目录: newdir
```

### 组合使用
```bash
fck mkdir -pv -m 777 parent/child
# 递归创建并显示详情，设置权限为 777
```

### 递归创建已存在的目录
```bash
fck mkdir existingdir
# 输出: 跳过: existingdir (已存在)
```

## 实现细节

### 1. 配置结构体

```go
type MkdirConfig struct {
    Targets   []string
    Parents   bool
    Mode      int
    Verbose   bool
}
```

### 2. 核心处理流程

```
1. 解析命令行参数，构建 MkdirConfig
2. 验证权限模式：
   - 检查权限值是否有效（八进制）
   - 设置默认权限（0755）
3. 创建目录：
   - 遍历所有目标路径
   - 如果 Parents=true，递归创建父目录
   - 如果 Parents=false，只创建目标目录
   - 处理目录已存在的情况
4. 设置权限：
   - 如果指定了 Mode，设置目录权限
5. 输出结果：
   - 如果 Verbose=true，显示创建的目录
   - 显示创建统计信息
```

### 3. 创建逻辑

#### 单个目录创建
```
1. 检查目录是否存在
2. 如果存在且 Parents=false，返回错误
3. 如果存在且 Parents=true，跳过
4. 如果不存在，创建目录
5. 如果指定了 Mode，设置权限
6. 如果 Verbose=true，输出创建信息
```

#### 递归创建（Parents=true）
```
1. 分解路径为各级目录
2. 从根目录开始，逐级创建
3. 如果目录已存在，跳过
4. 如果目录不存在，创建
5. 对每级目录设置权限
6. 如果 Verbose=true，输出每级目录的创建信息
```

### 4. 权限处理

支持的权限格式：
- 八进制：0755, 0777, 0644 等
- 十进制：493, 511, 420 等（不推荐）

权限解析：
```go
// 八进制字符串转整数
mode, _ := strconv.ParseInt("0755", 8, 64)
```

常用权限：
- 0755：所有者可读写执行，组和其他用户可读执行
- 0777：所有用户可读写执行
- 0700：仅所有者可读写执行
- 0750：所有者可读写执行，组和其他用户可读

### 5. 错误处理

支持的错误类型：
- 目录已存在（Parents=false 时）
- 权限不足
- 路径无效
- 磁盘空间不足
- 父目录不存在（Parents=false 时）

错误处理策略：
- 默认遇到错误停止
- Parents=true 时，跳过已存在的目录
- 提供详细的错误信息

## 边界情况处理

1. **空目标列表**：提示错误，不执行任何操作
2. **目录已存在**：
   - Parents=false：返回错误
   - Parents=true：跳过，继续执行
3. **路径包含特殊字符**：验证路径格式
4. **权限值无效**：使用默认权限或提示错误
5. **创建符号链接**：创建链接指向的目录
6. **并发创建**：确保线程安全
