# FCK 项目架构记忆

> **定位**: 一站式文件与系统管理工具集 | **技术栈**: Go 1.25.0 | **版本**: v1.8

## 一、目录结构

```
fck/
├── cmd/main.go              # 程序入口
├── internal/
│   ├── cli/                 # 26个命令的 flag 定义
│   ├── commands/            # 业务逻辑（按功能分包）
│   ├── types/               # 全局类型和常量
│   └── utils/               # 通用工具
├── docs/                    # 设计文档
├── vendor/                  # 自研依赖库
│   └── gitee.com/MM-Q/
│       ├── colorlib/        # 颜色输出
│       ├── comprx/          # 压缩解压
│       ├── go-kit/          # FS、Hash、Pool
│       ├── qflag/           # CLI 框架
│       ├── shellx/          # Shell 执行
│       └── verman/          # 版本管理
└── build.py                 # 跨平台编译脚本
```

## 五、关键命令特性

### cat 命令
- 支持语法高亮 (`-H`)、分页查看 (`-l`)
- 行号显示 (`-n`/`-b`)
- 特殊字符显示 (`-A`/`-E`/`-T`)

### head 命令
- 显示文件开头内容
- 支持按行数 (`-n`) 或字节数 (`-c`) 读取
- 多文件支持，自动显示文件名标题
- 管道输入支持

### tail 命令
- 显示文件结尾内容
- 支持按行数 (`-n`) 或字节数 (`-c`) 读取
- 实时追踪模式 (`-f`)，类似 `tail -f`
- 多文件支持，自动显示文件名标题
- 管道输入支持

### tr 命令
- 字符转换、删除、压缩功能
- 支持字符范围（如 `a-z`, `0-9`）
- 支持转义字符（`\n`, `\t`, `\\`）
- 删除模式 (`-d`)、压缩模式 (`-s`)、补集模式 (`-c`)
- 管道输入支持

### wc 命令
- 统计文件的行数、单词数、字节数、字符数
- 支持最大行长度统计 (`-L`)
- 多文件统计并显示总计
- 表格样式输出

### df 命令
- 显示磁盘空间使用情况
- 支持本地文件系统过滤 (`-l`)
- 按文件系统类型过滤 (`-t`)
- 显示总计行 (`--total`)
- 简洁模式和表格样式输出

### find 命令
- 名称/扩展名/大小/时间过滤
- 正则匹配、深度限制
- 对匹配文件执行操作（删除/移动/执行命令）
- 并发执行能力

### xargs 命令
- 分批处理 (`-n`, `-s`)
- 并行执行 (`-P`)
- 占位符替换 (`-i`, `-I`)
- Shell模式 (`--shell`)

### watch 命令
- 定时执行命令
- 差异高亮 (`-d`)
- 自动清屏、标题栏
- 精确计时模式

### md 命令
- Markdown预览
- 多主题样式 (`-s`)
- 分页器支持 (`-l`)
- 原始/渲染视图切换 (`-r`)
