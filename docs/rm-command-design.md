# RM 命令设计方案

## 功能概述
实现一个用于删除文件和目录的命令 `rm`，支持递归删除、强制删除、确认提示等功能，提供安全的文件删除操作。

## 核心功能

### 1. 基本删除功能
- 支持删除单个文件
- 支持删除单个目录（空目录）
- 支持删除多个文件/目录

### 2. 递归删除
- 支持递归删除非空目录及其所有内容
- 支持深度控制（限制递归深度）

### 3. 安全保护
- 支持确认提示（删除前询问用户）
- 支持只读文件保护（默认不删除只读文件）
- 支持显示删除进度

### 4. 强制删除
- 支持强制删除只读文件
- 支持忽略错误继续删除

### 5. 详细输出
- 支持显示删除的文件/目录列表
- 支持显示删除统计信息

## 命令选项设计

| 选项 | 短选项 | 说明 | 默认值 |
|------|--------|------|--------|
| `--recursive` | `-r` | 递归删除目录及其内容 | false |
| `--force` | `-f` | 强制删除（删除只读文件，跳过确认） | false |
| `--verbose` | `-v` | 显示删除的文件/目录 | false |

**注意**：
- 输出内容通过位置参数传递，支持多个文件/目录
- 支持通配符模式（如 `*.txt`, `./ven/*`）

## 使用示例

### 基本删除
```bash
fck rm file.txt
# 删除 file.txt
```

### 删除多个文件
```bash
fck rm file1.txt file2.txt file3.txt
# 删除多个文件
```

### 递归删除目录
```bash
fck rm -r directory/
# 递归删除 directory/ 及其所有内容
```

### 强制删除
```bash
fck rm -f readonly-file.txt
# 强制删除只读文件
```

### 删除前确认
```bash
fck rm -i important.txt
# 删除前询问: 删除 important.txt? (y/n)
```

### 显示删除详情
```bash
fck rm -v file.txt
# 输出: 删除: file.txt
```

### 模拟运行
```bash
fck rm -d -r directory/
# 输出将要删除的文件，但不实际删除
```

### 限制递归深度
```bash
fck rm -r -D 2 directory/
# 递归删除，但最多深入2层
```

### 组合使用
```bash
fck rm -rfv directory/
# 强制递归删除并显示详情
```

## 实现细节

### 1. 配置结构体

```go
type RMConfig struct {
    Targets    []string
    Recursive bool
    Force     bool
    Interactive bool
    Verbose   bool
    DryRun    bool
    MaxDepth  int
}
```

### 2. 核心处理流程

```
1. 解析命令行参数，构建 RMConfig
2. 验证目标路径：
   - 检查路径是否存在
   - 检查是否有权限
   - 检查是否为特殊路径（如根目录）
3. 删除操作：
   - 遍历所有目标路径
   - 对每个目标执行删除操作
   - 如果是目录且 Recursive=true，递归删除
   - 如果 Interactive=true，删除前确认
   - 如果 DryRun=true，只显示不实际删除
4. 输出结果：
   - 如果 Verbose=true，显示删除的文件/目录
   - 显示删除统计信息
```

### 3. 删除逻辑

#### 单个文件删除
```
1. 检查文件是否存在
2. 如果是只读文件且 Force=false，跳过
3. 如果 Interactive=true，询问用户确认
4. 如果 DryRun=false，执行删除
5. 如果 Verbose=true，输出删除信息
```

#### 目录删除（递归）
```
1. 检查目录是否存在
2. 读取目录内容
3. 对每个子项递归调用删除逻辑
4. 删除空目录
5. 检查递归深度限制
```

### 4. 确认提示

确认提示格式：
```
删除 <路径>? (y/n/a/q)
  y - 是，删除
  n - 否，跳过
  a - 全部是，删除所有
  q - 退出，不删除
```

### 5. 错误处理

支持的错误类型：
- 文件不存在
- 权限不足
- 目录非空且未启用递归
- 路径无效
- 删除失败

错误处理策略：
- 默认遇到错误停止
- 可配置忽略错误继续
- 提供详细的错误信息

## 边界情况处理

1. **空目标列表**：提示错误，不执行任何操作
2. **目标不存在**：跳过或提示错误（取决于配置）
3. **删除自身**：拒绝删除当前工作目录
4. **删除根目录**：拒绝删除系统根目录
5. **循环链接**：检测并跳过循环符号链接
6. **只读文件**：默认跳过，Force=true 时强制删除
7. **并发删除**：确保线程安全

## 安全考虑

- 检查路径是否在允许范围内
