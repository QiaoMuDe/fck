# Chmod 命令设计方案

## 功能概述
实现一个用于修改文件和目录权限的命令 `chmod`，支持递归修改、权限模式设置、详细输出等功能，提供便捷的权限管理操作。

## 核心功能

### 1. 修改文件权限
- 支持修改单个文件权限
- 支持修改多个文件权限
- 支持八进制权限模式（如 755、644）

### 2. 修改目录权限
- 支持修改单个目录权限
- 支持修改多个目录权限
- 支持递归修改目录及其内容的权限

### 3. 递归修改
- 支持递归修改目录及其所有子目录和文件
- 自动遍历目录树
- 支持跳过符号链接

### 4. 权限模式
- 支持八进制权限模式（如 755、644、777）
- 支持符号模式（如 u+rwx, g+rx, o+r）- 可选扩展

### 5. 详细输出
- 支持显示修改的文件/目录
- 支持显示权限变化
- 支持显示操作统计信息

### 6. 错误处理
- 检测权限是否足够
- 检测路径是否存在
- 提供友好的错误提示

## 命令选项设计

| 选项 | 短选项 | 说明 | 默认值 |
|------|--------|------|--------|
| `--recursive` | `-R` | 递归修改目录及其内容 | false |
| `--verbose` | `-v` | 显示修改的文件/目录 | false |
| `--changes` | `-c` | 只显示有变化的文件/目录 | false |
| `--quiet` | `-f` | 抑制错误信息 | false |

## 使用示例

### 修改单个文件权限
```bash
fck chmod 755 file.txt
# 将 file.txt 权限设置为 755
```

### 修改多个文件权限
```bash
fck chmod 644 file1.txt file2.txt file3.txt
# 将多个文件权限设置为 644
```

### 修改目录权限
```bash
fck chmod 755 directory/
# 将 directory/ 权限设置为 755
```

### 递归修改权限
```bash
fck chmod -R 755 directory/
# 递归修改 directory/ 及其所有内容的权限
```

### 详细输出
```bash
fck chmod -v 755 file.txt
# 输出: 修改权限: file.txt (0644 -> 0755)
```

### 只显示有变化的文件
```bash
fck chmod -c 755 file.txt
# 只在权限实际改变时显示
```

### 抑制错误信息
```bash
fck chmod -f 755 nonexistent.txt
# 不显示错误信息
```

### 组合使用
```bash
fck chmod -Rv 755 directory/
# 递归修改并显示详情
```

## 实现细节

### 1. 配置结构体

```go
type ChmodConfig struct {
    Mode      string
    Targets   []string
    Recursive bool
    Verbose   bool
    Changes   bool
    Quiet     bool
}
```

### 2. 核心处理流程

```
1. 解析命令行参数，构建 ChmodConfig
2. 解析权限模式：
   - 验证权限模式格式
   - 转换为 os.FileMode
3. 处理每个目标文件/目录：
   - 检查路径是否存在
   - 如果是目录且 Recursive=true，递归处理
   - 如果是文件或目录且 Recursive=false，直接修改
4. 输出结果：
   - 如果 Verbose=true，显示修改的文件
   - 如果 Changes=true，只显示有变化的文件
   - 显示操作统计信息
```

### 3. 权限修改逻辑

```
1. 获取当前权限
2. 解析目标权限
3. 比较权限是否相同
4. 如果不同：
   - 修改权限
   - 如果 Verbose=true，输出修改信息
   - 如果 Changes=true，输出修改信息
5. 如果相同：
   - 如果 Changes=true，跳过
   - 如果 Verbose=true，输出跳过信息
```

### 4. 递归处理逻辑

```
1. 遍历目录及其所有内容
2. 对每个文件/目录：
   - 跳过符号链接（可选）
   - 修改权限
   - 如果是目录，继续递归
3. 处理错误：
   - 如果 Quiet=true，抑制错误
   - 如果 Quiet=false，显示错误
```

### 5. 权限解析

支持的权限格式：
- 八进制：755, 644, 777, 700, 750 等
- 符号模式（可选扩展）：u+rwx, g+rx, o+r, a+x 等

权限解析：
```go
// 八进制字符串转整数
mode, _ := strconv.ParseInt("0755", 8, 64)
```

常用权限：
- 0755：所有者可读写执行，组和其他用户可读执行
- 0644：所有者可读写，组和其他用户只读
- 0777：所有用户可读写执行
- 0700：仅所有者可读写执行
- 0750：所有者可读写执行，组和其他用户可读

### 6. 错误处理

支持的错误类型：
- 权限不足
- 路径不存在
- 权限模式无效
- 符号链接错误

错误处理策略：
- 默认遇到错误停止
- Quiet=true 时，抑制错误信息
- 提供详细的错误信息

## 边界情况处理

1. **空目标列表**：提示错误，不执行任何操作
2. **权限模式无效**：提示错误，不执行操作
3. **文件不存在**：报错，提示文件不存在
4. **权限不足**：报错，提示权限问题
5. **符号链接**：可选择跳过或跟随链接
6. **递归循环**：检测并避免循环
7. **权限相同**：跳过修改，或显示提示

- 限制递归深度
